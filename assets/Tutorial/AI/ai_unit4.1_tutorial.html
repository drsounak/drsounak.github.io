★ The Two Golden Rules — Memorise These First

Universal with implication (∀ → ): "All A are B" → ∀x [ A(x) → B(x) ]
Existential with conjunction (∃ ∧ ): "Some A is B" → ∃x [ A(x) ∧ B(x) ]
The most common mistake in FOPL translation is mixing these up — writing ∃x [A(x) → B(x)] which is almost always wrong.

Level 01

Translation into First-Order Logic

Domain: All people  |  S(x) = x is a student  |  T(x) = x is a teacher  |  L(x,y) = x likes y  |  R(x,y) = x respects y
Q1 Every student likes some teacher.

Step-by-step breakdown

  • 1
    "Every student" → universal quantifier over x with S(x) as condition: ∀x S(x) →…
  • 2
    "likes some teacher" → existential quantifier over y: there exists y such that T(y) is true AND L(x,y) is true. Use ∧ with ∃.
  • 3
    Combine: for every x that is a student, there is at least one y that is a teacher and x likes y.
FOL Formula ∀x [ S(x) → ∃y ( T(y) ∧ L(x, y) ) ]
Explanation

The universal quantifier (∀) ranges over all people. The existential quantifier (∃) says "at least one". We use → (implication) with ∀, and ∧ (conjunction) with ∃ — this is the standard golden pattern.

Q2 No student respects every teacher.

Step-by-step breakdown

  • 1
    "No student respects every teacher" = it is not the case that some student respects every teacher.
  • 2
    Equivalently: for every student x, there exists at least one teacher y that x does NOT respect.
  • 3
    Two equivalent forms — Form 2 is more readable and preferred.
Form 1 — negation outside ¬∃x [ S(x) ∧ ∀y ( T(y) → R(x, y) ) ]
Form 2 — push negation inside (preferred) ∀x [ S(x) → ∃y ( T(y) ∧ ¬R(x, y) ) ]
Explanation

Both forms are logically equivalent. Form 2 is more readable: every student fails to respect at least one teacher. The negation (¬) is pushed inside using De Morgan's laws: ¬∀y φ ≡ ∃y ¬φ.

Q3 Some students like all teachers, and some teachers like all students.

Step-by-step breakdown

  • 1
    Part 1: ∃ a student who likes every teacher. (∃ outside, ∀ inside)
  • 2
    Part 2: ∃ a teacher who likes every student. (∃ outside, ∀ inside)
  • 3
    The two parts are joined by ∧ (AND).
Part 1 ∃x [ S(x) ∧ ∀y ( T(y) → L(x, y) ) ]
Part 2 ∃x [ T(x) ∧ ∀y ( S(y) → L(x, y) ) ]
Full Formula [ ∃x ( S(x) ∧ ∀y ( T(y) → L(x,y) ) ) ] ∧ [ ∃x ( T(x) ∧ ∀y ( S(y) → L(x,y) ) ) ]
Explanation

We use ∃ to say "some", and within that scope ∀ says "all teachers/students". Note x is reused as a bound variable in each separate conjunct — this is valid since the scopes do not overlap.

Q4 If a student respects a teacher, then the teacher likes that student.
  • 1
    "A student" and "a teacher" here mean ANY student x and ANY teacher y — universally quantified over all pairs.
  • 2
    Antecedent: S(x) ∧ T(y) ∧ R(x,y) — x is a student, y is a teacher, and x respects y.
  • 3
    Consequent: L(y, x) — the teacher y likes the student x. Note the argument reversal!
FOL Formula ∀x ∀y [ ( S(x) ∧ T(y) ∧ R(x,y) ) → L(y, x) ]
Explanation

We quantify over all pairs (x, y). The implication (→) captures the conditional. The reversal of arguments in L(y, x) is crucial: the teacher likes the student, not vice versa.

Q5 Only teachers respect themselves.
  • 1
    "Only P's do X" ≡ "If someone does X, then they are a P." The word "only" flips the implication direction.
  • 2
    Rewritten: If person x respects themselves R(x,x), then x must be a teacher T(x).
FOL Formula ∀x [ R(x, x) → T(x) ]
Watch Out — "Only" flips the arrow!

"Only teachers respect themselves" does NOT mean all teachers respect themselves.
It means self-respect implies being a teacher.
Compare: "All teachers respect themselves" → ∀x [T(x) → R(x,x)] ← this is the OPPOSITE direction.

Level 02

Nested Quantifiers and Identity

Domain: All people  |  P(x) = x is a politician  |  K(x,y) = x knows y  |  H(x) = x is honest  |  T(x,y) = x is taller than y  |  x=y (identity)
Q6 Every politician knows some other politician.
  • 1
    "Every politician" → universal quantifier over x, with P(x).
  • 2
    "knows some other politician" → existential quantifier over y, with P(y) and K(x,y).
  • 3
    "other" requires y ≠ x — the known politician must be a different person from x.
FOL Formula ∀x [ P(x) → ∃y ( P(y) ∧ K(x,y) ∧ x ≠ y ) ]
Explanation

The identity predicate x ≠ y (equivalently ¬(x=y)) ensures the known politician is distinct from x. Without this, a politician could satisfy the formula by "knowing themselves".

Q7 There is exactly one honest politician.
  • 1
    Existence: ∃ at least one honest politician. (∃x with H(x) ∧ P(x))
  • 2
    Uniqueness: Any two honest politicians x and y must be the same person. (uniqueness constraint)
  • 3
    Combine into the compact "exactly one" idiom.
Part 1 — Existence ∃x ( H(x) ∧ P(x) )
Part 2 — Uniqueness ∀x ∀y [ ( H(x) ∧ P(x) ∧ H(y) ∧ P(y) ) → x = y ]
Full Formula — Compact Form (standard idiom for ∃!) ∃x [ H(x) ∧ P(x) ∧ ∀y ( ( H(y) ∧ P(y) ) → y = x ) ]
The ∃! Idiom — Exactly One

The compact form is the standard FOL idiom for "exactly one" (uniqueness quantifier ∃!): the existential witness x exists, and any other y satisfying the same conditions must equal x. Memorise this pattern — it appears in exams frequently.

Q8 No one knows every dishonest person.
  • 1
    "Dishonest" = ¬H(x).
  • 2
    "Knows every dishonest person" = ∀y ( ¬H(y) → K(x, y) ).
  • 3
    "No one" = negate the above for all x, then push negation inside.
FOL Formula ∀x ¬ [ ∀y ( ¬H(y) → K(x, y) ) ]
Equivalent Form — negation pushed inside (preferred) ∀x ∃y ( ¬H(y) ∧ ¬K(x, y) )
Explanation

The equivalence: ¬∀y φ ≡ ∃y ¬φ, and ¬(A→B) ≡ A ∧ ¬B.
Reading the equivalent form: for every person x, there is some dishonest person y that x does not know.

Q9 The tallest person knows everyone.
  • 1
    The tallest person is unique: define as x such that for all y ≠ x, T(x, y) holds (x is taller than everyone else).
  • 2
    That person must know everyone: ∀z K(x, z).
  • 3
    Introduce x existentially (as the tallest person) and apply both constraints.
Tallness Condition ∀y ( y ≠ x → T(x, y) ) — x is taller than everyone else
Full Formula ∃x [ ∀y ( y ≠ x → T(x,y) ) ∧ ∀z K(x, z) ]
Definite Description

We existentially introduce x as the tallest person, constrain it with the tallness condition, and then assert K(x,z) for every z. This is called a definite description — describing a unique individual without naming it directly.

Q10 If anyone knows everyone, then that person is a politician.
  • 1
    "Anyone knows everyone" = ∀y K(x, y) for some x.
  • 2
    "That person is a politician" = P(x).
  • 3
    The conditional must hold for all such persons x — outer ∀x.
FOL Formula ∀x [ ∀y K(x, y) → P(x) ]
Explanation

The outer ∀x ranges over all people x. The antecedent ∀y K(x, y) checks whether x knows everybody. If this holds for some x, then P(x) must hold. The use of ∀x ensures the rule applies to every such person.

Level 03

Validity, Satisfiability, and Models

Three Verdicts — Know the Definitions

VALID — true in every possible model (every interpretation of the domain and predicates).
SATISFIABLE (not valid) — true in some model but not all (counterexample exists).
UNSATISFIABLE — false in every model; leads to contradiction. Strategy: assume it's true and derive a contradiction.

Q11 ∃x P(x) ∨ ∃x ¬P(x)
✓ VALID

Justification — Exhaustive Case Analysis

  • 1
    Case 1: The domain has at least one element a where P(a) = true. Then ∃x P(x) is true → disjunction is true.
  • 2
    Case 2: The domain has at least one element a where P(a) = false. Then ∃x ¬P(x) is true → disjunction is true.
  • 3
    These two cases are exhaustive — for any element, either P holds or it does not. At least one disjunct must always be true.
Conclusion

The formula is true in every non-empty model → VALID. It is essentially a tautology: "either something has property P, or something lacks property P."

Q12 ∀x P(x) ∨ ∀x ¬P(x)
~ SATISFIABLE (not valid)

Justification — Model Analysis

ModelConfiguration∀x P(x)∀x ¬P(x)Formula
Making it TRUEDomain={a}, P(a)=trueTRUEFALSETRUE
Making it FALSEDomain={a,b}, P(a)=T, P(b)=FFALSE (b fails)FALSE (a fails)FALSE
Conclusion

The formula says "everyone has P" OR "no one has P". A mixed world (some have P, some don't) makes both disjuncts false — this is the counterexample proving it's not valid. True in some models (pure worlds) but false in others → SATISFIABLE, NOT VALID.

Q13 ∀x (P(x) → Q(x)) ∧ ∃x P(x) ∧ ∀x ¬Q(x)
✗ UNSATISFIABLE

Proof by Contradiction — Assume it's true in some model

  • 1
    From ∃x P(x): there is some element a with P(a) = true.
  • 2
    From ∀x (P(x) → Q(x)) with x=a: since P(a) is true, Q(a) must be true.
  • 3
    From ∀x ¬Q(x) with x=a: Q(a) must be false.
  • 4
    Contradiction: Q(a) is both true (step 2) and false (step 3). Impossible.
Conclusion

Leads to contradiction in every model → UNSATISFIABLE. The three conjuncts cannot all be true simultaneously.

Q14 ∀x ∃y R(x,y) → ∃y ∀x R(x,y)
~ SATISFIABLE (not valid)

Understanding the Formula

StatementMeaning
Antecedent∀x ∃y R(x,y)Every x has SOME y it is related to (y may differ for each x)
Consequent∃y ∀x R(x,y)There is a SINGLE y related to ALL x (one common witness — stronger!)

Counterexample — Formula is FALSE

Counterexample Model Domain = {a, b} R(a,a) = true, R(b,b) = true, R(a,b) = false, R(b,a) = false Antecedent ∀x∃y R(x,y): a has witness a; b has witness b → TRUE Consequent ∃y∀x R(x,y): Need y such that R(a,y) AND R(b,y) both hold No such y exists → FALSE Formula: TRUE → FALSE = FALSE ✗

Model making it TRUE

Domain = {a}, R(a,a) = true: both sides trivially hold → formula TRUE.

Conclusion

True in some models, false in others → SATISFIABLE, NOT VALID. The consequent is strictly stronger than the antecedent — requiring one shared witness for all x, not a different y per x.

Q15 ∀x ∀y (R(x,y) → R(y,x)) ∧ ∃x ∃y (R(x,y) ∧ ¬R(y,x))
✗ UNSATISFIABLE

Proof by Contradiction

  • 1
    From ∃x ∃y (R(x,y) ∧ ¬R(y,x)): pick witnesses a, b such that R(a,b) = true and R(b,a) = false.
  • 2
    From ∀x ∀y (R(x,y) → R(y,x)) with x=a, y=b: since R(a,b) is true, R(b,a) must be true.
  • 3
    Contradiction: R(b,a) is both true (symmetry axiom) and false (from witness). Impossible.
Conclusion

The formula asserts R is symmetric (first conjunct) AND has an asymmetric pair (second conjunct) — a direct self-contradiction → UNSATISFIABLE.

Level 04

Resolution in First-Order Predicate Logic

Resolution — The Method

Resolution is a refutation-based proof technique. To prove goal G from premises, negate G, convert everything to CNF, and apply the Resolution rule until the empty clause □ is derived — proving G by contradiction.

ALGORITHM: Resolution Refutation Proof — 5 Steps
1

Write all premises as FOL formulas.

2

Negate the conclusion (goal) and add it to the premise set.

3

Convert every formula to Conjunctive Normal Form (CNF) / clause form using the 6-step CNF algorithm.

4

Apply Unification + Resolution rule to pairs of clauses: resolve {α ∨ P} and {β ∨ ¬P} → {α ∨ β}.

5

If the empty clause □ is derived → Contradiction → Original conclusion is PROVED ✓

R-Q1 Prove: Socrates is mortal.

Premises

  • All men are mortal: ∀x ( Man(x) → Mortal(x) )
  • Socrates is a man: Man(Socrates)

Step 1 — Convert to CNF Clauses

C1: ∀x(Man(x)→Mortal(x)) ≡ ∀x(¬Man(x)∨Mortal(x)) → {¬Man(x), Mortal(x)}
C2: Man(Socrates) → {Man(Socrates)}

Step 2 — Negate Goal

Negate Mortal(Socrates) → C3: {¬Mortal(Socrates)}

Step 3 — Resolution Derivation

Resolve C1 + C2  ·  Unifier θ = {x/Socrates}: {¬Man(x), Mortal(x)}θ + {Man(Socrates)} → {Mortal(Socrates)}
Resolve {Mortal(Socrates)} + C3: {Mortal(Socrates)} + {¬Mortal(Socrates)} → □ (Empty Clause)
✓ PROVED — Mortal(Socrates)
R-Q2 Prove: John is not a vegetarian.

Premises

  • Everyone who eats meat is not a vegetarian: ∀x ( Eats(x, meat) → ¬Vegetarian(x) )
  • John eats meat: Eats(John, meat)

CNF Clauses

C1: {¬Eats(x, meat), ¬Vegetarian(x)}
C2: {Eats(John, meat)}
C3 (negated goal): {Vegetarian(John)}

Resolution

Resolve C1 + C2  ·  θ = {x/John}: {¬Eats(x,meat), ¬Vegetarian(x)}θ + {Eats(John,meat)} → {¬Vegetarian(John)}
Resolve {¬Vegetarian(John)} + C3: {¬Vegetarian(John)} + {Vegetarian(John)} → □
✓ PROVED — ¬Vegetarian(John)
R-Q3 Prove: There exists a criminal. (Crime scenario)

Premises

  • P1: ∀x ( American(x) ∧ Weapon(y) ∧ Sells(x,y,z) ∧ Hostile(z) → Criminal(x) )
  • P2: Sells(West, M1, Nono)
  • P3: Weapon(M1)
  • P4: Hostile(Nono)
  • P5: American(West)

CNF Clauses

C1: {¬American(x), ¬Weapon(y), ¬Sells(x,y,z), ¬Hostile(z), Criminal(x)}
C2: {Sells(West, M1, Nono)}
C3: {Weapon(M1)}
C4: {Hostile(Nono)}
C5: {American(West)}
C6 (negate ∃x Criminal(x) → ∀x ¬Criminal(x)): {¬Criminal(x)}

Resolution Chain

C1 + C5  (θ={x/West}): → {¬Weapon(y), ¬Sells(West,y,z), ¬Hostile(z), Criminal(West)}
+ C3  (θ={y/M1}): → {¬Sells(West,M1,z), ¬Hostile(z), Criminal(West)}
+ C2  (θ={z/Nono}): → {¬Hostile(Nono), Criminal(West)}
+ C4: → {Criminal(West)}
+ C6  (θ={x/West}): {Criminal(West)} + {¬Criminal(West)} → □
✓ PROVED — West is a criminal → ∃x Criminal(x)
R-Q4 Prove: Mary loves the rain. (Chaining with multiple rules)

Premises

  • P1: ∀x ( Likes(x, rain) → Loves(x, rain) )
  • P2: ∀x ( Happy(x) → Likes(x, rain) )
  • P3: Happy(Mary)

CNF Clauses

C1: {¬Likes(x, rain), Loves(x, rain)}
C2: {¬Happy(x), Likes(x, rain)}
C3: {Happy(Mary)}
C4 (negated goal): {¬Loves(Mary, rain)}

Resolution — Chain Proof

C2 + C3  (θ={x/Mary}): {¬Happy(x), Likes(x,rain)} + {Happy(Mary)} → {Likes(Mary, rain)}
{Likes(Mary,rain)} + C1  (θ={x/Mary}): → {Loves(Mary, rain)}
{Loves(Mary,rain)} + C4: {Loves(Mary,rain)} + {¬Loves(Mary,rain)} → □
Chain

Happy(Mary) → Likes(Mary, rain) → Loves(Mary, rain). Three premises linked by two resolution steps.

✓ PROVED — Loves(Mary, rain)
R-Q5 Show the premises are inconsistent. (Tweety cannot fly)

Premises (claimed consistent — prove they are NOT)

  • P1: ∀x ( Bird(x) → Flies(x) )
  • P2: Bird(Tweety)
  • P3: ¬Flies(Tweety)

No negation of goal needed — derive □ directly from the premises.

CNF Clauses

C1: {¬Bird(x), Flies(x)}
C2: {Bird(Tweety)}
C3: {¬Flies(Tweety)}

Resolution — 2 Steps to Contradiction

C1 + C2  (θ={x/Tweety}): {¬Bird(x), Flies(x)} + {Bird(Tweety)} → {Flies(Tweety)}
{Flies(Tweety)} + C3: {Flies(Tweety)} + {¬Flies(Tweety)} → □
Conclusion

The three premises are mutually INCONSISTENT (unsatisfiable). The empty clause is derived in just 2 resolution steps. The classical "Tweety is a Bird that cannot fly" scenario — a famous example of the Frame Problem and non-monotonic reasoning.

✓ PREMISES ARE INCONSISTENT

Common Mistakes in Resolution

Watch Out!

Mistake 1: Forgetting to negate the goal before adding it to the clause set. Resolution proves by contradiction — you must add ¬Goal.

Mistake 2: Applying unification incorrectly. In R-Q3, the unifier must bind ALL three variables simultaneously: θ = {x/West, y/M1, z/Nono}. Partial unification leaves literals unresolved.

Mistake 3: Failing to convert to CNF before resolving. The implication A→B must become ¬A∨B before resolution can be applied.

Mistake 4: Confusing resolution with modus ponens. Resolution is a single rule for both forward and backward reasoning; it subsumes modus ponens as a special case.

Key Takeaways

∀ uses →, ∃ uses ∧ — the golden rule of FOL translation.
"Only" flips → — "Only A does X" means X → A, not A → X.
Exactly one: ∃x[φ(x) ∧ ∀y(φ(y)→y=x)] — existence plus uniqueness.
Resolution = negate goal + CNF + unify + derive □.
